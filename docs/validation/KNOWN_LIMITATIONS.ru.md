# Известные ограничения — единый перечень

> Перевод документа [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md) (узбекский — основной текст; при расхождении действует он).

> **Состояние:** `ENGINE_VERSION` 2.10.0, P14 (2026-11-20).
> Этот перечень не вводит новых ограничений — он только собирает их. Источники: `CLAUDE.md` («Joriy holat bo'yicha eslatmalar» — «Заметки о текущем состоянии»), `docs/RISKS.md`, `tests/cases/DISCREPANCIES.md`, `docs/VALIDATION_MATRIX.md`, `docs/LINTER_RULES.md` §4, `docs/PLAN.md`. При противоречии приоритет имеют `CLAUDE.md` и `docs/RISKS.md`.
> ID устойчивы: при закрытии пункт не удаляется — он помечается «закрыто» (с датой и версией); новый пункт добавляется в конец.

**Тип:** `unverified` — источника нет в репозитории либо сравнение не проводилось (не обязательный тест); `BETA` — модуль unverified, в результате всегда предупреждение; `не реализовано` — функции нет; `ожидает подтверждения` — применено временное решение проекта, требуется подтверждение владельца; `не просмотрено` — не просмотрено вручную в реальном браузере / на принтере; `todo` — известное расхождение, тест в состоянии todo; `остаточный риск` — известное принятое ограничение; `шаг владельца` — действие, которое должен выполнить владелец; `запланировано` — следующий этап.

Столбец «Влияние» приводит только последствие, названное в источнике; если в источнике его нет — «—».
